# 上傳到 GitHub 並繳交

1. 登入 GitHub，開啟 https://github.com/new 。
2. Repository name 填 `family-fund-sepolia`，說明可填 `家庭基金：Ethereum Sepolia 鏈上信託 DApp`。
3. 若要老師不登入也可查看，選 Public。若選 Private，須另外邀請老師帳號存取。
4. 這份專案已附 README，因此建立時不用再初始化 README。按 Create repository。
5. 空白儲存庫頁面點 `uploading an existing file`。若已有檔案，選 Add file → Upload files。
6. 解壓縮交付的 ZIP，打開 FamilyFund 資料夾。把裡面的檔案與資料夾拖曳到上傳區，不是只上傳整個 ZIP。
7. 確認根目錄有 README.md、FamilyTrustContinuous.sol、FamilyTrust_Continuous_DApp.html，保留 tests、docs、licenses 資料夾。
8. 提交訊息可填 `Initial commit: Family Fund Sepolia DApp`，按 Commit changes。
9. 在 README 的部署資訊補上這次新信託地址，並可加入一筆成功發放交易的 Etherscan 連結。
10. 複製儲存庫首頁網址給老師。

網址格式範例：`https://github.com/你的帳號/family-fund-sepolia`。這是格式示意，不是已建立的網址。
