# 家庭基金 Family Fund：持續給付版

本次只更新操作介面，已部署的同版單一信託可直接沿用，不需重新部署。信託本身只需部署 `FamilyTrustContinuous.sol` 的 `FamilyTrustContinuous` 一個合約。既有 FAM 代幣與父母 Safe 繼續使用，不需要代理合約、邏輯合約或另外呼叫 initialize。

## 給付與手足借款：維持原版兩種操作

| 操作 | 結果 |
|---|---|
| `distributeNextPeriod()`／結算並發放 | 到期後結算一期，直接把三人全部已分配未領款轉入其錢包；受益人不必另外領款 |
| `settleNextPeriod()`／只結算 | 到期後結算一期，款項保留在信託，記入各人的未領款；適合示範手足借款 |
| `withdrawAll()` | 受益人領自己的全部已分配未領款 |
| `payAllBeneficiaries()` | 任何人可替三人發放既有未領款；收款地址固定 |
| `checkUpkeep(bytes)` | 免費查詢是否到期或可從缺款暫停恢復 |
| `performUpkeep(bytes)` | 外部執行器送出交易：運行中到期就結算並直接發放；缺款暫停補足後則先恢復並重新等一期 |

**有直接發放功能，但未設定無人操作的定時執行器。** Ethereum 合約不會自己每 20 秒送交易；需要按 DApp 按鈕，或另接持續運作、有 Gas 的外部執行器。這份 DApp 的自動重新讀取只查詢資料，不會自動送出付款交易。20 秒是最早執行門檻，不保證準點成交。沒有交易時，期數、餘額與暫停狀態不會自行改變。

**示範手足借款時按「只結算」。** 本金來自出借人當期未領款。若已直接發放或有人替三人領完，就無法用同一筆已領款出借；需於後續一期再次只結算並保留款項。外部執行器若正在直接發放，也應先停止該執行器，避免借款示範時被代領。合約保留原版允許任何人代為發放的規則。

## 持續運作規則

- 無總期數上限。預設每期 20 秒，哥哥／弟弟／妹妹各 500 FAM，合計 1,500。
- 急用金池補足目標 5,000 FAM。任何新入金先補足急用金，其餘才進定期給付餘額。定期發放不挪用急用金或既有未領款。
- 存款金額不限。建議先存 10,000：急用金 5,000、定期餘額 5,000，可付三期，餘 500。
- 第一次至少存 6,500 FAM 才足以補足急用金並啟動完整一期。
- 第一次由父親或 Safe 啟動。每次成功結算後重新等待一期，不補扣錯過的時間。
- 到期交易若發現定期餘額不足，記錄缺款暫停，回傳 false，不增加期數，也不部分付款。
- 缺款暫停後，使用 deposit／syncDonation 補足會自動恢復，重新等待 20 秒，再從原下一期接續。
- 父母手動暫停後，只能透過 Safe 恢復；補款或外部執行器不能越過手動暫停。
- 暫停時停止新增期別、提前支領、借款、急用金申請與核准；已分配款仍可領，取消與否決仍可處理。
- 父母 Safe 可改期長（暫停時，10 秒至 365 天）與指定未來一期分配（總額仍為 1,500 FAM，不能低於既有承諾）。這是預先提供的設定功能，不是升級程式碼。
- 沒有 upgradeToAndCall、initialize、代理轉送、可換邏輯地址或任意執行入口。部署後無法新增程式原本沒有的功能。

## Remix 部署：只部署這一個信託

1. 上傳 `FamilyTrustContinuous.sol`。
2. Solidity 選 **0.8.34**；Optimizer 開啟、Runs **200**；EVM **shanghai**；viaIR **關閉**。OpenZeppelin 引用鎖定 **5.0.2**。
3. 編譯後，Deploy & Run 使用 MetaMask／Browser Extension、Sepolia、父親帳號。Value 設 **0**。
4. CONTRACT 下拉選 **FamilyTrustContinuous**。不要選 IERC20、IFamilySafe 或其他介面。
5. 展開 Deploy 的四個建構欄位，照下表填入，確認後部署一次。

| 欄位 | 填入 |
|---|---|
| token_ | `0x950F3735f0a939A3Ce80aD5c5b8d56b50cff1C58` |
| funder_ | `0xE06e7F3f9DF7C863f91b872B0872d4d77A8aCC11` |
| safe_ | `0x9bDE8a27D271A12911f7d0e0A7BfaFcc59539B65` |
| children_ | 下方完整陣列，含中括號與雙引號 |

```text
["0x635593b7CdBD12E51aEFbB0b8fE96b5C5c35aEa9","0xADF682B8274eb6ed87A0fC92F5238A1975613391","0xF7693be0220Edea21Bb4d7A075D7322b0d3C6141"]
```

另附 `CONSTRUCTOR_ARGUMENTS.txt`，可直接複製欄位。部署時會檢查代幣為 6 位小數、Safe 是兩位 owner 且門檻 2、出資人是其中一位家長、小孩地址不重複且不是父母。

成功後記錄 **FAMILYTRUSTCONTINUOUS AT …** 的地址。這一個地址就是信託地址，用來授權 FAM、入金、DApp 連線及 Safe 管理。不需呼叫 initialize，也不需執行舊版 fundAndActivate。

## 開啟 DApp 與入金

1. 解壓縮到電腦，開啟有 `FamilyTrust_Continuous_DApp.html` 的資料夾。
2. 在檔案總管按 Ctrl＋L，輸入 `cmd`，按 Enter。
3. 輸入 `python -m http.server 8000 --bind 127.0.0.1`，保持視窗開著。
4. 用已安裝 MetaMask 的 Chrome／Edge 開啟 `http://127.0.0.1:8000/`，點選 HTML。不要用 ChatGPT 預覽視窗連錢包。
5. 在頁面上方填入新信託地址，載入並連接 MetaMask、Sepolia。
6. 用父親帳號存入例如 10,000 FAM。DApp 通常會先要求 approve，再要求 deposit，兩筆都要確認。
7. 按「啟動／恢復」。20 秒後選「結算並發放」，或為借款示範選「只結算」。

DApp 自帶 ethers，可離線載入介面，但鏈上查詢和交易仍需要網路。每筆寫入交易都需要執行帳號有 Sepolia ETH 作 Gas。所有設定和數據以新合約鏈上結果為準。

## 暫停後兩種多簽取回

在「父母管理」直接提出提案，父母各自簽署，簽滿後在同一頁執行。不需要下載 JSON 或開啟 Transaction Builder。

| 選項 | 轉到父母 Safe 的資金 | 保留 |
|---|---|---|
| 只取回定期餘額 | 指定定期餘額 | 急用金與受益人既有未領款 |
| 連急用金一起取回 | 全部未分配定期餘額與急用金池 | 受益人既有未領款 |

DApp 若發現尚未暫停，會在同一份 Safe 批次提案先暫停再取回。父親個人錢包不能直接呼叫管理功能。連急用金取回前，須先處理待審急用金；可取消、否決、清理到期，或由 Safe 在暫停時取消。Safe 按鈕是產生新提案的工具，執行後不會消失；回 DApp 重新讀取確認帳本。

未來已約定的借款還款不會被刪除，但仍需要補入資金並成功結算到還款期才會支付；取回資金可能延後給付。既有未領款不會被取回。

## 三項彈性功能

- 急用金：一位小孩申請，另外兩位都核准後立即轉到申請人錢包；有效 24 小時。不能核准自己或重複投票。後續新入金優先補池至 5,000。
- 提前支領：第一期結算後，可提前動用下一期自己的未承諾面額，每個下一期最多一次。面額 100 現在實領 95，下一期扣 100；5 留在定期資金。
- 手足借款：用出借人當期未領款支付本金；借款人承諾在當期＋2 或之後還更多，受該期可用配額限制。每位借款人每個已結算期最多成交一次，未接受邀請跨期失效。

## 測試與檔案

`TEST_RESULTS.txt` 是本機合約測試結果，`UI_TEST_RESULTS.txt` 是前端對本機 EVM 的流程驗證。原合約測試使用兩位 owner 的替身。新版父母管理另以官方 Safe 1.4.1 singleton、官方 ProxyFactory 建立的代理及官方 MultiSendCallOnly 做本機測試，結果見 SAFE_ADMIN_TEST_RESULTS.txt。這些測試不代替真實瀏覽器 MetaMask 或 Sepolia 操作。沒有移動你的 Sepolia FAM。

主要檔案：合約、單檔 HTML、ABI、建構參數、編譯設定、標準編譯輸入、測試程式、可重建前端的 app.js／template.html／build-ui.cjs。只操作 Remix 和 HTML 不需要 npm；要重跑開發測試可先 npm install，再 npm test。

## 父母直接簽署操作

1. 下載新版 HTML 覆蓋原檔，使用原本的 localhost 網址開啟，載入同一個信託地址。
2. 切到父親帳號，選「父母管理」，按「提出暫停」或填入期別及金額後按「提出分配修改」。
3. 在下方「父母提案」核對操作、信託地址與 Safe 序號，按「簽署提案」，於 MetaMask 簽署。
4. 切換母親帳號，再按「簽署提案」。兩次簽署都不收 Gas，且此時尚未修改鏈上設定。
5. 簽名顯示 2／2 後，任一位家長按「執行提案」，確認 MetaMask 交易，執行者支付 Sepolia ETH Gas。確認 Safe 的 ExecutionSuccess 後，介面才顯示執行成功。
6. 恢復、取回兩種餘額、修改期長、父母取消急用金也使用同一流程。需要先暫停的操作會以官方 MultiSendCallOnly 原子批次執行。

提案與簽名存在同一瀏覽器、同一網站來源的 localStorage。重新整理或切換 MetaMask 帳號會保留；不會自動同步到另一台電腦、另一個瀏覽器、另一個 port 或 Safe 網站。這版不需要 Safe 服務 API key，不會要求私鑰或助記詞。

同一個信託一次處理一份本機提案。要放棄舊提案，可按「提出作廢提案」，仍需父母兩人重新簽署並執行。作廢成功才會消耗 Safe 的該序號並使原提案失效，單純建立作廢提案不會撤銷原簽名。若 Safe 序號已由其他交易使用，舊提案會失效，須重新提出及簽署。

簽署與執行前都會檢查 Safe 的兩位 owner、門檻 2、網路、序號、EIP-712 雜湊及目前信託地址。批次操作也會核對官方批次合約的鏈上程式碼雜湊。已到期的分配或其他條件失效時，執行前檢查會擋下，不能只因簽名已齊就保證可執行。

## MetaMask 偵測

新版支援 EIP-6963、傳統 window.ethereum.providers，以及 ethereum#initialized 延遲注入。仍必須在有啟用 MetaMask 的瀏覽器開啟。預覽／內嵌視窗、file://、localhost 偵測失敗時會分別顯示排查步驟。有其他錢包時，不會直接用其他錢包代替 MetaMask。

請用操作 Remix 的同一個 Chrome／Edge 使用者設定檔。以本機網站開啟後按 Ctrl＋F5 重新載入新版，再按連接。若仍失敗，保留含網址列與新診斷訊息的截圖以確認實際開啟環境。
